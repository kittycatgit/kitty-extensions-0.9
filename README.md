## Install

Add this URL in Paperback under Settings → Extensions:

```
https://paperback.samipmainali.dev/kitty
```

Or open [this link](paperback://addRepo?url=https%3A%2F%2Fpaperback.samipmainali.dev%2Fkitty) on your device.
